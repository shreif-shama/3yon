# سوق البيت الذكي (تصميم أولي)

واجهة ويب احترافية باللغة العربية لسوق الأدوات المنزلية والأدوات الكهربائية، تشمل:

- خطط اشتراك للبائعين.
- تسجيل بائع جديد مع اختيار الخطة.
- صفحة منتجات مع معرض صور، سعر، مواصفات.
- زر اتصال مباشر وزر واتساب لكل بائع.
- سلة مشتريات تجريبية مع عرض طرق الدفع (فيزا / فودافون كاش).
- لوحة تحكم مبدئية للبائع ولوحة مدير كاملة من ناحية التصميم.
- اعتماد خط **Cairo** وواجهة RTL متكاملة.

## تشغيل المشروع

للمعاينة محليًا:

```bash
python3 -m http.server 8080
```

ثم افتح:

`http://localhost:8080`

## ملاحظات تقنية

- هذا الإصدار هو **Prototype Front-end** عالي الدقة بصريًا.
- أي تكامل حقيقي مع المدفوعات (Visa/Vodafone Cash) يحتاج Backend آمن + مزود دفع.
- إدارة الصلاحيات (مدير/بائع/عضو) تحتاج API وقاعدة بيانات وجلسات مصادقة.
